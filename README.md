# Homework 2 - Dart Programming

This repository contains solutions for Homework 2, covering core Dart concepts including collections, object-oriented programming, inheritance, polymorphism, and asynchronous programming.

## Project Structure

```text
homework-2/
├── ex1/
│   └── problem_1.dart  # List operations
├── ex2/
│   └── problem_2.dart  # Book class
├── ex3/
│   └── problem_3.dart  # Asynchronous sum
├── ex4/
│   └── problem_4.dart  # Vehicle inheritance and fuel consumption
├── ex5/
│   └── problem_5.dart  # Product totals by category
├── ex6/
│   └── problem_6.dart  # Exception handling with Future
├── ex7/
│   └── problem_7.dart  # Payment polymorphism
├── ex8/
│   └── problem_8.dart  # Find a pair of indices
└── ex9/
    └── problem_9.dart  # Concurrent asynchronous tasks
```

## Running the Exercises

Each file contains a self-contained `main()` function and can be executed independently:

```bash
dart run ex1/problem_1.dart
dart run ex2/problem_2.dart
dart run ex3/problem_3.dart
dart run ex4/problem_4.dart
dart run ex5/problem_5.dart
dart run ex6/problem_6.dart
dart run ex7/problem_7.dart
dart run ex8/problem_8.dart
dart run ex9/problem_9.dart
```
